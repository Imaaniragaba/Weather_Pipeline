Title: Weather Pipeline Project

This project is a multi-file Python application to ingest, process and anlayze data from local weather sensors.

How to setup the virtuual environment: (Step by step) 
Step 1: In your VS Code terminal and run "python -m venv venv"
Step 2: Activate the virtual environment by running ".venv\Scripts\Activate.ps1"
Step 3: In case you get an error telling you that running scripts is disabled on this system, run " Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass " and then run the previous line again
Step 4: If successful, you will see the word (venv) at the start of the next prompt line

How to run main.py:
Step 1: Navigate to the waether_pipeline folder
Step 2: Run py main.py
